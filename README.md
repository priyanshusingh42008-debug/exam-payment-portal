# Examination Payment Portal

A professional, generic examination-fee portal starter with:
- student payment page
- supplied QR image
- ₹2,500 fee
- UTR/reference submission
- payment status lookup
- administrator verification panel
- receipt available only after verification
- responsive mobile layout

## Run
1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open http://localhost:3000

## Important
The supplied QR is a personal UPI/PhonePe QR. This package does not represent it as an official college payment channel and does not provide automatic proof that money was received. Only use it where the account holder is authorized to collect the fee.

For a real institutional deployment, replace it with an authorized merchant/institution QR or payment-gateway integration and add proper administrator authentication, HTTPS, database security, audit logs, and privacy controls.
